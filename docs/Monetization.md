# Monetization

## Phases

### Phase 1: Google AdSense
- Positions: homepage resource stream, category list, resource detail footer, desktop sidebar
- No hero ads, no pop-ups, no auto-play
- Track RPM monthly

### Phase 2: Affiliate
- Promote free tool upgrades (AI Pro, VPS, domains, Notion, Canva Pro, Cursor, Copilot, etc.)
- Mark as `Affiliate` clearly
- Only on free resource pages

### Phase 3: Sponsorship
- Featured Tool
- Weekly Sponsor
- Category Sponsor
- Must be labeled

### Phase 4: Newsletter
- Weekly Free Resources
- AI Free Tools
- Open Source Weekly

### Phase 5: Premium (Optional)
- Sync favorites
- Weekly curated collections
- API access
- Ad-free
- Supplementary revenue only

## Implementation

- Create Google AdSense account
- Verify domain ownership
- Insert Auto Ads initially, then manual placements
- Monitor Core Web Vitals
