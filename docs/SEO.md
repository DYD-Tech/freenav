# SEO

## Strategy

- Static pages with meaningful URLs
- Every page has unique Title, Description, Keywords
- OG Image and Twitter Card meta tags
- JSON-LD structured data
- Auto-generated sitemap.xml and robots.txt
- RSS Feed

## URL Structure

```
/                      # Homepage
/search                # Search page
/category/ai           # Category listing
/resource/chatgpt      # Individual resource
/rss.xml               # RSS feed
/sitemap.xml           # Sitemap
/robots.txt            # Crawl directives
```

## Meta Tags

Each page must include:
- `<title>` — concise, unique
- `<meta name="description">` — 150–160 chars
- `<meta name="keywords">` — comma-separated tags
- `<meta property="og:title">`
- `<meta property="og:description">`
- `<meta property="og:image">`
- `<meta property="og:url">`
- `<meta name="twitter:card">` — `summary_large_image`

## JSON-LD

Resource pages include structured data:
```json
{
  "@context": "https://schema.org",
  "@type": "Product",
  "name": "...",
  "description": "...",
  "url": "..."
}
```

## Sitemap

Auto-generated by `@astrojs/sitemap` and custom `collect-resources.mjs`.

## robots.txt

```
User-agent: *
Allow: /
Sitemap: https://freenav.dev/sitemap.xml
```
